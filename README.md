# Munteum

문틈(Munteum)은 책을 읽다가 마음에 머문 문장과 그때의 생각을 조용히 기록해두는 독서 기록 앱입니다.  
현재 이 저장소는 **Expo 기반 모바일 MVP**를 중심으로 개발하고 있습니다.

## 프로젝트 목표

문틈의 목표는 독서 기록을 많이 남기게 만드는 것이 아니라,  
**문장 사이에 머문 생각을 부담 없이 기록하고 다시 꺼내볼 수 있게 하는 것**입니다.

- 독서 중 스쳐 지나가기 쉬운 문장과 감상을 가볍게 붙잡아두는 경험
- 책 단위 기록과 날짜 단위 기록을 함께 돌아볼 수 있는 구조
- 복잡한 기능보다 기록 흐름 자체를 빠르게 만드는 모바일 MVP 구축

## 서비스 소개

- 독서 중 스쳐 지나가기 쉬운 문장과 감상을 가볍게 붙잡아두기 위한 서비스입니다.
- 빠르게 적고, 나중에 다시 꺼내보고, 책 단위와 날짜 단위로 흐름을 돌아보는 경험에 집중합니다.
- 한 권의 책에 대해 `읽고 싶음`, `읽는 중`, `완독` 상태를 관리합니다.
- 인상 깊은 문장, 페이지, 생각을 짧게 남길 수 있습니다.
- 날짜별 기록을 다시 꺼내보며 독서 흐름을 돌아볼 수 있습니다.
- 완독한 책과 올해의 기록을 한눈에 확인할 수 있습니다.

## 핵심 화면

- `홈`: 지금 읽는 책과 최근 기록 확인
- `책장`: 상태별 책 관리와 책 추가
- `캘린더`: 날짜별 기록 다시 보기
- `마이`: 완독 수, 기록 수, 최근 읽은 책 확인

## 구현 방식

- `Expo` 기반 모바일 앱
- `React Native` UI 구성
- `TypeScript`로 타입 안전성 유지
- `AsyncStorage` 기반 로컬 상태 저장
- 현재는 서버 연동 전 단계의 로컬 MVP 구조

## 현재 개발 기준

- `munteum-mobile/`: 현재 주력으로 개발 중인 모바일 MVP
- `archive-web-prototype/`: 보관 중인 초기 웹 프로토타입
- 지금 단계에서 중심 대상은 `웹 MVP`가 아니라 `모바일 MVP`

## 실행 위치

현재 앱 실행과 개발은 `munteum-mobile/` 폴더 기준으로 진행합니다.
